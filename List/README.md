# List（単方向リスト）

Javaの授業で学習した単方向リストの実装記録です。

## 実装した機能

- AddTop（先頭への追加）
- AddTail（末尾への追加）
- Print（リストの表示）
- Size（要素数の取得）
- Reset（初期化）
- Insert（指定位置への挿入）
- Get（指定位置の値の取得）
- Set（指定位置の値の変更）
- Delete（指定位置の削除）
- Search（指定位置の値の確認）

## 使用技術

- Java

## ファイル構成

- `List.java`：リストの処理を実装
- `Element.java`：リストの各要素を管理

## 学習内容

- 単方向リスト
- Elementによるデータ管理
- nextによる要素同士の接続
- top・tailによる先頭と末尾の管理
