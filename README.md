# Java Data Structures

Javaの授業で学習したデータ構造の実装記録です。

## Queue（キュー）

配列を使用してQueueを実装しました。

### 実装した機能
- Enqueue（データの追加）
- Dequeue（データの取り出し）
- Size（要素数の取得）
- Reset（初期化）
- Print（Queueの状態表示）

### 使用技術
- Java

### ファイル構成
- `Queue.java`：Queueの処理を実装
- `QueMain.java`：入力受付と操作処理

### 学習内容
- FIFO（先入れ先出し）
- 配列によるQueueの管理
- リングバッファ方式
- head・tail・cntによる要素管理
