## Blackjack（ブラックジャック）

Javaの授業で作成したブラックジャックゲームです。

### 実装した機能

- 52枚のカードを使用
- 山札のシャッフル
- 最初に2枚のカードを配る
- プレイヤーが追加でカードを引く
- カードの数字に応じた点数計算
- 21を超えた場合のバースト判定
- カードを引くか終了するかの選択

### ファイル構成

- `Card.java`：カードの情報を管理
- `Deck.java`：山札の生成とシャッフル
- `BrackJack.java`：ゲームの進行と点数計算

### 学習内容

- クラスとオブジェクト
- 配列によるカード管理
- 条件分岐と繰り返し処理
- boolean型による状態管理
- Aceの点数調整
