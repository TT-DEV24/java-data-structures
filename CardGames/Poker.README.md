# Poker（ポーカー）

Javaの授業で作成したポーカーゲームです。

## 実装した機能

- 52枚のカードを生成
- カードのシャッフル
- 5枚のカードを配る
- 最大3回までカードを交換
- カードの数字による並び替え
- ポーカーの役判定

## 判定できる役

- ハイカード
- ワンペア
- ツーペア
- スリーカード
- ストレート
- フラッシュ
- フルハウス
- フォーカード
- ストレートフラッシュ
- ロイヤルストレートフラッシュ

## ファイル構成

- `Card.java`：カードの情報を管理
- `Deck.java`：52枚の山札とシャッフル処理
- `Poker.java`：カード交換と役の判定

## 使用技術

- Java
- Scanner
- Random

## 学習内容

- クラスとオブジェクト
- 配列によるカード管理
- 2重ループによる並び替え
- 条件分岐による役判定
- メソッドを利用した処理の分割
