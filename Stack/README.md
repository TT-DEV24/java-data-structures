# Stack（スタック）

Javaの授業で学習したデータ構造の実装記録です。

## 実装した機能

- Push（データの追加）
- Pop（データの取り出し）
- Size（要素数の取得）
- Reset（初期化）
- Print（Stackの状態表示）
- 数字以外が入力された場合の入力チェック

## 使用技術

- Java
- Scanner

## ファイル構成

- `Stack.java`：Stackの処理を実装
- `SrackMain.java`：入力受付と操作処理

## 学習内容

- LIFO（後入れ先出し）
- 配列によるStackの管理
- spによる要素数とデータ位置の管理
- Scannerによる標準入力
- 入力値のチェック処理
